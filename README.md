# Simple Manager

## Descricao do projeto

O Simple Manager e uma aplicacao web para gestao de equipes, criada para apoiar rotinas de Recursos Humanos com foco em organizacao, produtividade e comunicacao em um unico ambiente.

A aplicacao segue arquitetura SPA (Single Page Application), com navegacao por rotas no React Router.

## Tecnologias utilizadas

- React 19
- Vite 8
- TypeScript 5
- Tailwind CSS 3
- React Router DOM 7
- React Hook Form 7
- ESLint 9

## Como executar localmente

Pre-requisitos:

- Node.js 18 ou superior
- npm

Instalacao e execucao:

```bash
npm install
npm run dev
```

Build e preview de producao:

```bash
npm run build
npm run preview
```

Scripts disponiveis:

- npm run dev
- npm run build
- npm run preview
- npm run lint
